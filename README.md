# E-commerce Dashboard

Interface d'administration e-commerce développée avec **React**.

## Présentation

Ce projet est un dashboard permettant de gérer et suivre les différentes activités d'une boutique en ligne à travers une interface simple et moderne.

## Fonctionnalités

### Dashboard

la page Dashboard est vide car je me suis concentré sur la page Produit

### Produits

* Statistiques de vente
* Chiffre d'affaires
* Commandes
* Indicateurs de performance
* Affichage en liste ou en grille
* Recherche par nom, catégorie et SKU
* Filtrage par statut
* Tri par prix, stock et date
* Pagination
* Affichage du stock, des ventes et du statut

### Navigation

* Sidebar organisée par sections
* Header
* Recherche globale
* Fil d'Ariane dynamique

## Organisation

Le projet est organisé par fonctionnalités afin de garder une structure claire.

* **components/ui** : composants réutilisables comme Input, Button, EmptyState, Loading, etc.
* **features** : fonctionnalités spécifiques de l'application.
* **pages** : différentes pages de l'application.
* **styles** : fichiers CSS.

## Technologies

* React
* JavaScript
* React Router
* Lucide React
* CSS
* Vite

## Installation

Cloner le projet, installer les dépendances avec `npm install`, puis lancer le serveur avec `npm run dev`.

## Déploiement

Le projet peut être déployé sur **Vercel**.
